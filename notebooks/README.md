# Sarathi AI — Notebooks

Run these notebooks in order on Google Colab:

| # | Notebook | Purpose |
|---|---|---|
| 01 | `01_data_collection.ipynb` | Download IPC, Gita, Wikipedia data |
| 02 | `02_build_vectorstore.ipynb` | Chunk docs and build FAISS index |
| 03 | `03_qlora_finetuning.ipynb` | QLoRA fine-tune Mistral 7B |
| 04 | `04_evaluation.ipynb` | BLEU/ROUGE evaluation |

## Quick Start (Copy to Colab)
